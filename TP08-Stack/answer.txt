a. What is Queue? 
Queue is a linear data structure that follows FIFO (first in first out) principle.

b. What are the variables and functions used in Queue data structure? 
A Queue structure primary uses variables to track the start and the end points and function to manage the first in, first out flows of the data.

c. Give the main differences between using Linked list and using Queue. 
The main differences between using Linked list and using Queue:

- Queue:
follows FIFO principle
Restricts operations to only two ends

- Linked List:
Does not enforce the specific order
provide total flexibility
